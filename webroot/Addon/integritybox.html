tuneScope Settings

Configure the options for each installed module.

Target Apps controls the apps included in the module's target list.

Keybox controls whether the module updates its keybox configuration.

Build Fields controls whether the module updates its build-field configuration.

Options are available only when the corresponding module is installed. These settings are not for Tricky Store users. Your keybox and target list updates by default so you don't need to configure anything manually.
