About Prop Spoofer

Prop Spoofer scans your device for detectable properties that integrity checkers and spoofing modules leave behind.

Reset Props Restores security properties like USB debug, verified boot, and build type back to stock factory values.

Duck Props Removes properties that DuckDetector uses to identify custom ROMs or modified systems.

PIF Props Deletes Play Integrity related spoofing data including Pixel overrides and keybox flags.

Detection Props Removes dynamically found hook-related properties (pphooks, pihook, pixelprops). May re-enable your ROM's built-in spoofing verify and disable manually if needed.

ROM Hide Dynamically searches all properties for ROM-related keywords (Lineage, Evolution, crDroid, etc.) and deletes any matches found.
