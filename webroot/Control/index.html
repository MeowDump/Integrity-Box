What does this do?

Update Channel
OTA : Stable vs Beta
Switches the module's OTA update source. Stable receives tested releases. Beta receives early builds with latest fixes but may contain bugs.
Quick Settings
Zygiskless Mode
Enable this if you are on a Pixel stock ROM or a ROM with built-in Play Integrity spoofing. It disables Zygisk-based injection to avoid conflicts.
Developer Mode
Enables verbose logging inside the module. Only use for debugging. Many banking and streaming apps detect verbose logs and may refuse to launch. You should not enabled this toggle unless you're reporting a bug.
Lite Mode
Battery-saving mode. Reduces background processing of spoofing intensity. Best for daily drivers who want minimal overhead.
Miscellaneous
Customize ZN
You should enable this if you're using ZygiskNext. It automatically configured the best setup for your apps & modules by tweaking memory type, linker hooks, and denylist enforcement.
UI Style : Classic vs Modern
Switches the WebUI visual theme. Classic uses the old UI layout. Modern uses new UI layout.
Sync with Canary
Enables seamless, independent updates for language packs and hotfix patches without requiring a module upgrade or device reboot.
Processing
Basic Mode
Fastest and safest processing of prop generation
Normal Mode
Balanced between speed and thoroughness for prop generation.
Extreme Mode
Maximum spoofing depth for prop generation.
Save to Internal Storage
Export Keybox.xml
Generates a valid keybox.xml file in your device’s internal storage (/sdcard) whenever you trigger the Integrity Box action. The generated file can then be manually imported into your custom ROM’s spoofing settings. Recommended for users running Integrity Box in ZYGISKLESS Mode. (ROM's inbuilt spoofing).
Export PIF.json
Generates a valid meow.json file in your device’s internal storage (/sdcard) whenever you trigger the Integrity Box action. The generated file can then be manually imported into your custom ROM’s spoofing settings. Recommended for users running Integrity Box in ZYGISKLESS Mode. (ROM's inbuilt spoofing).
